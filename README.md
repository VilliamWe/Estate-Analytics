# Estate Analytics

Внутренний веб-сервис аналитики объектов коммерческой недвижимости и оценки эффективности экспозиций.

Проект разработан в рамках дипломной практики и выпускной квалификационной работы. Система предназначена для сотрудников брокерской компании и позволяет вести объекты недвижимости, учитывать экспозиции, анализировать показатели и сравнивать объекты между собой.

## Функции MVP

- авторизация сотрудников
- роли `admin` и `employee`
- справочники типов объектов, районов и каналов экспозиций
- CRUD объектов недвижимости
- CRUD экспозиций
- карточка объекта
- dashboard с основными показателями
- аналитика и графики
- сравнение объектов
- импорт объектов из CSV
- административный раздел пользователей
- feature-тесты ключевых сценариев

## Установка и запуск

1. Установить зависимости PHP:

composer install

2. Установить зависимости frontend:

npm install

3. Настроить файл .env

Пример параметров подключения к базе данных:

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=estate_analytics
DB_USERNAME=root
DB_PASSWORD=

4. Сгенерировать ключ приложения:

php artisan key:generate

5. Выполнить миграции и сиды:

php artisan migrate:fresh --seed

6. Запустить frontend:

npm run dev

7. Запустить приложение:

php artisan serve
